# 大まかな指示

- CSS ファイルを作成せよ
  - ファイルを作成する前に下記の「制約」と「方針」に合致するか検証せよ
    - 下記に「制約」がないときは制約がないので検証不要
    - 下記に「方針」がないときは方針がないので検証不要
- 対話モードなら
  - 不明な点は質問せよ
  - 方針について決定し、それを述べて、ユーザーに確認した後 作業をせよ
    - ユーザーのプロンプトで方針の言及がない、
      あるいは「別の方針で」と言及があったときは、
      下記の「方針」を大前提にして自由な方針を模索せよ
    - ユーザーのプロンプトで方針の言及があったときは、それに沿った
      方針でブラッシュアップせよ

# 方針

- 配色やデザインは「女の子が可愛いと思う」こと

# 制約

- 出力ファイルの絶対パスは `この文書と同じフォルダ/ファイル名`
  - ファイル名は、この文書ファイルと同じフォルダ内の NUMBERING スクリプトを
    実行した その出力とする. 同名のファイルがあるときは上書きせよ

- テンプレート

```
body {
    ...
}

body::after {
    ...
}

body::before {
    ...
}
```

- padding, margin, border-radius, font 系のプロパティは使わない
- `...` には、例えば 以下のようなものを入れて良い
  - `background-image: repeating-linear-gradient(〜);`
  - `clip-path: shape ( 〜 );`
