# 大まかな指示

- CSS ファイルを作成せよ
  - ファイルを作成する前に下記の「制約」と「方向性」に合致するか検証せよ
    - 下記に「制約」がないときは制約がないので検証不要
    - 下記に「方向性」がないときは方向性がないので検証不要
- 対話モードなら不明な点は質問せよ

# 制約

- CSS のファイル名は、この文書ファイルと同じフォルダ内で
  この文書ファイルの拡張子を css にしたファイル名にせよ
  - 既に同名のファイルがあるときは上書きせよ
- この文書ファイルと同じフォルダ内で
  この文書ファイルの拡張子を`画像ファイルの拡張子`にした
  画像ファイルがあるのでアスペクト比を変えずに背景画像として全画面表示する
- body, body::after, body::before に対する指定のみとせよ
- margin, padding, font 関連の属性は使用禁止

なし
